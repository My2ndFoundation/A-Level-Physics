# Baryon Number

## Core Idea

Baryon number $B$ is a conserved quantum number that counts "how much baryon" a system contains. It is conserved in every known particle interaction — strong, electromagnetic, and weak.

## Meaning

Assignment rules (AQA-examinable):

- Baryons (e.g. proton, neutron): $B = +1$.
- Antibaryons (e.g. antiproton, antineutron): $B = -1$.
- Mesons, leptons, and photons: $B = 0$.
- Each quark carries $B = +\tfrac{1}{3}$; each antiquark carries $B = -\tfrac{1}{3}$. Three quarks therefore give a baryon $B = +1$; a quark–antiquark pair gives a meson $B = 0$.

**Conservation rule.** In any allowed reaction,

$$\sum B_{\text{initial}} = \sum B_{\text{final}}.$$

This rule is the reason a proton cannot decay into a positron and a neutral pion within current experimental limits — total baryon number would change from $+1$ to $0$.

## Everyday Intuition

Baryon number behaves like a bookkeeping label: whatever you bring into the room, you leave with. If a baryon is destroyed, an antibaryon must be destroyed with it, or a new baryon must be created somewhere.

## Why It Matters

Baryon-number conservation is one of the four routine checks for AQA particle reactions, along with charge, lepton number, and (for strong reactions) strangeness. Together they decide whether a proposed reaction is allowed before any energy calculation is even attempted.

**Example — $\beta^{-}$ decay:**

$$n \rightarrow p + e^{-} + \bar{\nu}_{e}$$

Baryon numbers: $1 = 1 + 0 + 0$. ✓

**Example — proton-only decay (forbidden):**

$$p \nrightarrow e^{+} + \pi^{0}$$

Baryon numbers: $1 \ne 0 + 0$. Forbidden.

## Common Mistakes

- Assigning $B = +1$ to mesons. Mesons have $B = 0$ because they contain one quark and one antiquark.
- Forgetting that antibaryons have $B = -1$. An antiproton is not "$B = +1$ with a minus sign on charge".
- Ignoring quarks when checking quark-level reactions. Use $B = +\tfrac{1}{3}$ per quark.
- Confusing baryon number with mass number $A$. They have the same numerical value for ordinary nuclei but are conceptually different quantities.
